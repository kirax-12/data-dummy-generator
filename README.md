# Generator Data Dummy Indonesia

**Demo live:** [data-dummy-generator di GitHub Pages](https://kirax-12.github.io/data-dummy-generator/)

Web app statis buat membuat data dummy khas Indonesia untuk keperluan testing dan pengembangan aplikasi: nama, email, nomor HP, alamat, kota, pekerjaan, perusahaan, dan umur — semuanya fiktif hasil acakan di browser. Hasilnya bisa diunduh sebagai JSON atau CSV, atau disalin sebagai JSON.

Dibuat oleh **Remike Dev**.

## Fitur

- **5–1.000 baris** sekali buat, diatur dengan slider.
- **Kolom bisa dipilih** — nama (selalu ada), email, telepon, alamat, kota, pekerjaan, perusahaan, umur.
- **Nuansa Indonesia beneran** — kolam nama depan/belakang Indonesia, nama jalan dan kota dari berbagai daerah, awalan nomor HP operator Indonesia, format alamat RT/RW, dan nama perusahaan pola "PT …".
- **Ekspor lengkap** — unduh JSON, unduh CSV (dengan escaping yang benar), atau salin JSON ke clipboard.
- **Pratinjau tabel** — 50 baris pertama ditampilkan supaya bisa dicek sebelum diunduh.

## Catatan Etika

Semua data di halaman ini fiktif dan dibuat acak; kemiripan dengan orang sebenarnya adalah kebetulan. Tujuannya untuk testing software — jangan dipakai untuk menipu, spam, atau pendaftaran palsu.

## Teknologi

HTML · CSS · JavaScript murni, tanpa framework dan tanpa build step.
